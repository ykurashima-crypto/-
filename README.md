# ぬりログ｜塗装屋さんの業務効率アプリ

塗装業の現場が**毎日使う・入力が簡単・効果が見えやすい**ことを最優先に作った業務アプリです。
ビルド不要・インストール不要の **PWA（オフライン対応）** として動きます。サーバーは不要で、
データは端末内（localStorage / IndexedDB）に保存されます。

## できること（第1段階：現場DX ＋ 見積の先取り）

### 職人モード
- **今日の現場**（稼働中の現場一覧）
- **写真を撮る**：現場選択 → 工程（施工前/中/後）→ コメント → 撮影。複数枚まとめて保存
- **日報を書く**：作業内容・使用材料・作業時間・問題/追加工事・写真添付 → 送信
- **問題・追加工事の報告**（口頭依頼トラブル・利益漏れの防止）

職人画面には**金額（見積・受注・粗利）を一切表示しません**（現場が使い続けられるように）。

### 職人画面は5つだけ（今日 / 写真 / 日報 / 報告 / 明日）
- **今日**：今日の現場・集合時間・住所＋地図・「今日やること」チェックリスト・必要な写真・注意/約束＋大きな3ボタン（写真/日報/報告）
- **写真**：現場が1件なら自動紐付け→撮影→6分類を選ぶだけ→「続けて撮れます」
- **日報**：「今日 何しましたか？」🎤話して入力 → 「この内容で提出しますか？」と確認してから提出
- **報告**：追加工事/不具合/事故・ヒヤリハット/お客様要望/材料不足/その他を大ボタンで（管理者に届く）
- **明日**：明日の現場・集合時間・住所＋地図・作業・注意（無ければ「まだ登録されていません」）
- 金額・見積・請求・原価・案件管理は職人画面に**一切表示しない**

### 職人の「予定」ビュー
- **次に行く現場**・近い工程予定（日付順）・進行中の現場一覧
- 各現場の**工期（着工〜完工予定）・作業時間（集合〜終了）・作業フェーズ（工程順／完了・今ここ・未）**
- **納期に対して前倒し/遅れ/予定通り**を色バッジで表示
- 日報の「今日完了した工程」を選ぶと工程表の進捗が進み、前倒し/遅れ判定に反映される

### はじめの設定（オンボーディング）
- **デモ（端末内保存）**：初回起動で「個人/法人プランの選択 → 屋号・電話・住所・振込先」を1画面で登録して開始
- **本番（クラウド）**：メールで**新規登録**・ログイン・**パスワード再設定**。ログイン後、
  「会社を新しく作る（プラン選択）」または「**招待コードで参加**」を選択。
  管理者は「共有」タブの**招待コード**を家族・職人に伝えるだけで参加してもらえる

### 管理者モード
- **ダッシュボード**：稼働中の現場、未請求/入金待ちの金額、写真/日報件数、
  「💸お金が漏れるぞ」アラート（請求漏れ・入金漏れ・見積放置・写真不足・連絡忘れ）
- **お金の漏れをワンタップで解消**：アラートや現場画面から
  「🧾請求書を作った（請求日・入金予定日を記録）」「💰入金を確認した（入金日を記録）」
  「📞電話する／✔連絡済み」「🧮見積を作る」を直接実行。完工→請求→入金の流れが記録として残る
- **新規案件は3項目で30秒登録**：「お名前/現場名・電話・次の予定日」だけで仮登録。直後に
  「現地調査をする／見積を作る／写真を撮る／詳しく入れる／後で入力」の導線を表示。住所・金額・日付は後から編集で追記
- **ホーム＝今日やること**：最上部に優先順（お金の漏れ→仕事の漏れ）でタスクを表示し、各タスクに
  行動ボタン（請求書を作る／入金済みにする／見積を作る／現地調査する／写真を追加／連絡した）を直結
- **カレンダー表示**：案件タブで「一覧／📅カレンダー」を切替。現調・見積提出・着工・完工・入金予定を月表示（日付タップで案件へ）
- **地図**：現場・顧客の住所をGoogleマップで開く（電話発信ボタンは廃止）
- **バックアップ／復元**：共有タブから、案件・顧客・写真までを**1ファイルに保存**でき、端末が変わっても**復元**できる（クラウド利用時はSupabase側にも保存）
- **画面内の操作案内**：各画面に💡ヒントを表示（×で消すと再表示しない）。共有タブから「操作ガイドをもう一度表示」で復活
- **🤖 AI事務員（無料）**：見積追客・入金のお願い・完工→請求・着工連絡などの**連絡文を自動で下書き**、日報の**まとめ**も作成。コピーしてLINE/メールへ。APIキー不要・端末内生成（より自然な生成はLLM接続で有効化可）
- **顧客管理**：一覧・検索（名前/電話/住所）、登録・編集・削除、**📞電話番号だけの仮登録**、
  顧客ごとの**案件履歴**、「この顧客で新規案件」。問合せ経路は選択式（紹介/HP/チラシ/ポータル/元請け/リピーター/その他）
- **案件一覧**：ステータス絞り込み、新規案件登録
- **案件ステータス**：新規問い合わせ → 現調待ち → 見積作成中 → 見積提出済み → 追客中
  → 受注 → 工事中 → 完工 → 請求済み → 入金済み
- **現場詳細**：案件情報、写真（工程別）、日報、ステータス変更
- **現地調査**：建物情報（種別/築年数/階数/外壁材/屋根材/塗装面積/足場/駐車）と
  **劣化状態を選択式**（チョーキング/クラック/塗膜剥離/色あせ/コーキング劣化/カビ/苔/鉄部さび/木部劣化/雨漏り）で記録。
  メモは音声入力しやすい構成。**塗装面積を見積へ自動引き継ぎ**、写真撮影へも導線
- **見積（明細＋粗利）**：塗装業テンプレート（足場/高圧洗浄/下塗り/中塗り/上塗り…）から
  明細（数量・単位・単価）を組み、小計・値引き・消費税・税込合計を自動計算。
  同時に原価を入れて**粗利率を社内チェック**（基準25%未満／人工漏れ／値引き超過／赤字を警告）
- **工程管理（縦型工程表）**：標準12工程（足場/高圧洗浄/下地/養生/下塗り/中塗り/上塗り/付帯部/検査/手直し/完工/足場解体）を一括作成。
  各工程の予定日・完了を記録し、**雨天延期は理由＋日数を選ぶと以降の工程もまとめてずらせる**。完了数で進捗表示
- **音声入力（無料）**：日報の作業内容・問題、案件メモ、かんたん登録の名前欄に🎤マイク。
  話すと文字化し、電話番号・日付は自動で拾う。未対応ブラウザは手入力にフォールバック。
  保存はボタンで確認してから（高精度な項目分解はLLM＝有料APIが必要・下記参照）
- **追加工事の写真・金額・承認**：案件詳細から登録（内容・金額・理由・写真）。
  **お客様確認画面**で承認/却下（簡易署名）。承認済みは**請求書へ自動反映**し、未請求はホーム「今日やること」に表示
- **写真→施工写真報告書を自動化**：写真は案件に自動紐付け・**工程別6分類**（施工前/中/後/材料缶/不具合/追加工事）・撮影日時/撮影者/一言メモを保存。
  写真を選ぶだけで**施工写真報告書PDF**（案件名・顧客名・現場住所・工程別の写真とコメント）を出力
- **完工→請求書を連動**：ステータス「完工」で請求書作成の導線を表示。見積/契約金額から**請求書の下書き**（顧客・案件・金額・消費税・支払期限・振込先・備考）を生成し、
  記録すると請求済み→入金待ち→入金済みを管理。完工済み未請求・入金期限超過はホーム「今日やること」に表示
- **見積書・請求書PDF**：自社情報（屋号・住所・電話・登録番号・振込先・ロゴ）を入れた
  A4書類を出力。**ブラウザの「PDFで保存」でそのままLINE・メール送信**（依存ライブラリ無し・
  システムフォント描画で日本語の文字化けなし）。請求書は税込→税抜を自動逆算し振込先を表示

## 使い方

### 1人で試す（サーバー不要）

ローカルで開くだけで動きます（写真機能とPWA化のため簡易サーバー推奨）。

```bash
python3 -m http.server 8099
# → ブラウザで http://localhost:8099/index.html
```

スマホでは「ホーム画面に追加」でアプリのように起動できます（オフライン動作）。
画面右上で「職人 / 管理者」を切り替えます。初回はサンプル案件が自動投入されます。

### オンライン体験版（設定不要・すぐ開ける）

公開リポジトリのファイルを正しいMIMEで配信するCDN（githack）経由で、**有効化やビルド設定なしに
ブラウザからすぐ開けます**（サーバーレスのため**データは各自の端末内に保存**される体験版。
共有機能を使う場合のみ「共有」タブで外部サーバーURLを指定します）。

**体験版URL（最新ブランチを配信）:**

```
https://raw.githack.com/ykurashima-crypto/-/claude/eager-pasteur-l55tr3/index.html
```

PC・スマホのブラウザでそのまま開けます。職人/管理者の切替、写真・日報・案件・見積まで操作可能です。

> 全アセットが公開取得できることを確認済み。相対パス構成のためCDNのサブパス配信でも動作します。

### durable に自前ホストする場合（GitHub Pages）

GitHub Pages で配信したい場合は、**初回のみ**リポジトリ設定が必要です
（Pagesサイトの新規作成はActionsのトークンでは行えないため）:

1. リポジトリ → **Settings** → **Pages**
2. **Build and deployment** → Source = **GitHub Actions**（または **Deploy from a branch** → `claude/eager-pasteur-l55tr3` / root）
3. 同梱の `.github/workflows/pages.yml` を Actions タブから手動実行（GitHub Actions を選んだ場合）

公開URL: `https://ykurashima-crypto.github.io/-/`

### 複数人・複数端末で共有する（同梱サーバー）

PCで共有サーバーを起動し、フロント（PWA）も同じサーバーから配信します。
**追加ライブラリのインストールは不要**です（Node.js 標準機能のみ）。

```bash
npm start          # = node server/server.js  （既定ポート 8787）
# → http://localhost:8787 を各端末のブラウザで開く
```

1. 各端末でアプリを開き、下部タブ **「共有」** へ
2. **チームコード（合言葉）** を入力（例: `ito-toso-2026`）。サーバーURLは空欄でOK（同一オリジン）
3. 「チームに参加して同期」をタップ

同じチームコードの職人・管理者の間で、**案件・日報・写真・見積**が同期されます。
ヘッダーに「共有中」と表示され、変更は自動で双方向同期されます（オフライン時はローカルに溜め、
オンライン復帰時に自動送信）。

> スマホからPCのサーバーに接続する場合は、サーバーURLに `http://<PCのIP>:8787` を指定します
> （同一Wi-Fi内）。社外からも使うなら、このサーバーをクラウド（HTTPS）へ配置してください。

## 技術構成

- フロント・バックエンドとも**依存ライブラリゼロ**。ビルド工程なし
- フロント：バニラ JS（ES Modules）。データは `localStorage`（案件・日報・見積）＋ `IndexedDB`（写真Blob）
- 写真は保存時に長辺1600pxへ自動縮小して容量を節約
- `manifest.webmanifest` ＋ `sw.js` で PWA / オフライン対応
- バックエンド：Node.js 標準 `node:http` のみ。データはJSONファイル、写真はディスク保存

### 同期の仕組み（オフラインファースト）

- ローカルを常に正としてオフラインでも操作でき、オンライン時にサーバーと差分同期
- **送信**：端末時計の `updatedAt` で「前回送信以降に変更したレコード」を抽出して送る
- **受信**：サーバーが書き込みごとに採番する**単調増加 `rev`** をカーソルにして差分を取得
  （→ 端末間の時計ズレに影響されず、更新の取りこぼしが起きない）
- **競合解決**：`updatedAt` による Last-Write-Wins。削除はトゥームストーンで伝播
- **写真**：メタ情報は上記同期、Blob実体は `PUT/GET /api/blob/:id` で別途アップロード/ダウンロード

```
index.html
css/styles.css
js/
  app.js            ルーター・ロール切替・同期バッジ
  db.js             保存層（localStorage / IndexedDB）＋同期メタ(updatedAt/tombstone)
  model.js          ステータス定義・集計・画像縮小・初期データ
  ui.js             DOM/トースト/モーダル/写真サムネ
  sync.js           共有同期クライアント（差分送受信・Blob転送）
  views/
    worker.js       職人ホーム
    admin.js        ダッシュボード・案件一覧
    site.js         現場詳細・日報フォーム・写真撮影
    estimate.js     見積・粗利計算（警告付き）
    settings.js     共有設定（チーム参加・同期状態）
server/
  server.js         共有サーバー（API＋PWA配信、node:http）
  store.js          チーム別ストア（rev採番・LWWマージ・Blob保存）
package.json        npm start で起動（依存なし）
manifest.webmanifest, sw.js, icons/
```

### API

| メソッド | パス | 用途 |
| --- | --- | --- |
| POST | `/api/sync` | 差分の送受信 `{ teamCode, cursor, changes }` → `{ changes, cursor }` |
| PUT  | `/api/blob/:id` | 写真Blobのアップロード |
| GET  | `/api/blob/:id` | 写真Blobの取得 |

## 今後のロードマップ（優先順位順）

導入済みの第1段階に続き、効果の大きい順に拡張します。

- **第2段階（営業・利益管理）**：追客リマインド強化、追加工事の電子承認・サイン、
  見積PDF出力、過去類似案件との価格差チェック
- **第3段階（経営管理）**：工程・職人配置、勤怠・現場別人工、請求・入金管理、
  アフターフォロー（保証・再塗装通知）

最初から全機能を作り込むと入力項目が増えて現場が使わなくなるため、
**写真・日報 → 案件管理 → 見積・粗利** の順で現場定着を優先しています。

> ※ 1人で使う場合はサーバーレス（端末内保存）、チームで使う場合は同梱の共有サーバーで
> 複数端末に同期できます。社外利用や本格運用ではHTTPS化・認証強化・定期バックアップを推奨します。
