# 権限一覧

## 現在実装済みのロール

| ロール | 説明 | できること |
|---|---|---|
| `admin` | 管理者（経営者/親方本人） | 全データの閲覧・追加・編集・削除（論理）、案件/顧客/見積/調査/工程の管理、請求・入金記録、PDF出力、自社情報、招待コード発行 |
| `worker` | 職人 | 閲覧、日報・写真の**追加**、**自分の**投稿の編集。案件の編集/削除・顧客・見積・粗利・お金まわりは不可 |

- 職人画面（worker）は経営情報（顧客一覧・粗利・お金が漏れるぞ）を**表示しない**。現場が使い続けられることを優先。
- 役割は、デモモードは右上トグル、クラウドモードは `profiles.role` で自動決定（手動トグルは無効化）。

## 強制レイヤ（多層）

1. **RLS（主・サーバー側）**：`supabase/schema.sql`。他社データは取得・更新自体ができない。
2. **クライアント表示制御（補助）**：タブ/ボタンの出し分け。RLSの代わりにはしない。

## 会社作成・参加

| 操作 | 関数 | 条件 |
|---|---|---|
| 会社を新規作成し管理者になる | `create_my_company(name, plan)` | 呼び出し元が未所属のときのみ |
| 招待コードで会社に参加（職人として） | `join_company(code)` | 呼び出し元が未所属＋コード一致 |

招待コードは「共有」タブに表示。新規登録した相手がコード入力で同じ会社に入る。

## 法人プランの役割（基盤実装済み・`js/roles.js`）

7役割を定義し、画面のUIモード（職人5画面 / 管理画面）と権限判定を提供：

| ロール | 区分 | UI | 金額閲覧 | 管理操作 |
|---|---|---|---|---|
| `owner` 経営者 | 事務系 | 管理 | ✅ | ✅ |
| `admin` 管理者 | 事務系 | 管理 | ✅ | ✅ |
| `office` 事務 | 事務系 | 管理 | ✅ | ✅ |
| `sales` 営業 | 事務系 | 管理 | ✅ | ✅ |
| `manager` 現場管理 | 事務系 | 管理 | ✅ | ✅ |
| `craftsman` 職人 | 現場系 | 職人5画面 | ✗ | ✗ |
| `partner` 協力会社 | 現場系 | 職人5画面 | ✗ | ✗ |
| `worker`（旧称/個人） | 現場系 | 職人5画面 | ✗ | ✗ |

- `js/roles.js`：`uiMode()`（field→職人UI / office→管理UI）、`canSeeMoney()`、`canManage()`、`roleLabel()`。
- 画面の出し分けはこれを使用。`profiles.role` のCHECK制約は7役割に拡張済み（`supabase/schema.sql`）。
- **職人・メンバー管理（名簿）**：`members` コレクション（名前・役割・電話・有効/無効）。
  案件の「担当」割当の候補に使う（ログインユーザー profiles とは別の名簿）。共有タブ →「職人・メンバー管理」。
