# 権限一覧

## 現在実装済みのロール

| ロール | 説明 | できること |
|---|---|---|
| `admin` | 管理者（経営者/親方本人） | 全データの閲覧・追加・編集・削除（論理）、案件/顧客/見積/調査/工程の管理、請求・入金記録、PDF出力、自社情報、招待コード発行 |
| `worker` | 職人 | 閲覧、日報・写真の**追加**、**自分の**投稿の編集。案件の編集/削除・顧客・見積・粗利・お金まわりは不可 |

- 職人画面（worker）は経営情報（顧客一覧・粗利・お金が漏れるぞ）を**表示しない**。現場が使い続けられることを優先。
- 役割は、デモモードは右上トグル、クラウドモードは `profiles.role` で自動決定（手動トグルは無効化）。

## 強制レイヤ（多層）

1. **RLS（主・サーバー側）**：`supabase/schema.sql`。他社データは取得・更新自体ができない。
2. **クライアント表示制御（補助）**：タブ/ボタンの出し分け。RLSの代わりにはしない。

## 会社作成・参加

| 操作 | 関数 | 条件 |
|---|---|---|
| 会社を新規作成し管理者になる | `create_my_company(name, plan)` | 呼び出し元が未所属のときのみ |
| 招待コードで会社に参加（職人として） | `join_company(code)` | 呼び出し元が未所属＋コード一致 |

招待コードは「共有」タブに表示。新規登録した相手がコード入力で同じ会社に入る。

## 計画中のロール（フェーズ2以降・未実装）

- 個人プラン：`owner`（本人＝全操作）/ `family`（家族・事務補助＝見積・請求・顧客・案件は可、経営設定/アカウント削除は不可）
- 法人プラン：`owner` / `admin` / `office`（事務）/ `sales`（営業）/ `manager`（現場管理）/ `craftsman`（職人）/ `partner`（協力会社＝指定現場のみ）
