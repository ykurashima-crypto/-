# 既知の問題・未実装機能

## 既知の問題 / 制約

- **クラウド通電は未検証**：このリポジトリのロジック・スキーマ・RLS・RPCは整備済みだが、
  実Supabaseでの新規登録→会社作成→同期→他社分離の通し確認は未実施（ライブ環境が必要）。
  本番運用前に `supabase/schema.sql` を再Run し、`supabase/test_rls.sql` 相当の確認を推奨。
- **自社情報は端末内保存**：見積書/請求書ヘッダー・振込先・ロゴ・プランは `localStorage`(`js/company.js`)。
  クラウドで複数端末共有する場合、端末ごとに設定が必要（将来 `companies`/organizations 行へ移行予定）。
- **PDFはブラウザ印刷方式**：モバイルでポップアップブロック時は出力できない（警告表示あり）。
  余白等はブラウザの印刷設定に依存。
- **同一オリジンでデモ→本番切替時**：旧localStorageのデモデータが残る場合がある（通常は別オリジンのため発生せず）。
- **写真容量**：Storage無料枠を超えると有料化の主因。長辺1600px縮小済みだが大量運用時は要監視。

## AI事務員：無料でできる範囲 / 有料(LLM)が要る範囲

- **無料（実装済み・`js/ai.js`）**：定型文＋データ差し込みによる連絡文の下書き（追客/入金/完工/着工）、
  日報の要点まとめ（直近の作業・問題を箇条書き）、連絡すべき案件の抽出。端末内生成・APIキー不要。
- **有料（LLM API・未接続）**：自由発話からの高精度な項目分解、文体の自然な生成、長文の意味要約、
  クレーム傾向分析、見積内容の抜け漏れチェック等。
- **接続方針**：APIキーはフロントに置かない。`js/config.js` の `aiEndpoint`（Supabase Edge Function 等の
  サーバー）を設定すると `ai.js` の `aiGenerate()` が利用可能になる設計。料金は採用するLLMの従量課金。
